# TZ — Minecraft Forge 1.20.1

Мод для пользовательской карты Minecraft на Forge 1.20.1.

## Реализуемый контент

- Отдельная творческая вкладка **TZ** со всеми предметами и блоками мода.
- 11 вариантов запертых дверей с внешним видом ванильных дверей: все типы древесины из Minecraft 1.20.1.
- Ключ, который привязывается к конкретным координатам двери при использовании с приседанием.
- Подходящий ключ открывает дверь на 60 секунд; затем дверь автоматически закрывается.
- Обычное взаимодействие с запертой дверью не открывает её.
- Ограничение инвентаря: хотбар и четыре крайние левые ячейки верхнего ряда обычной сетки доступны как «Секретные карманы»; остальные ячейки сетки помечены замками и очищаются с переносом предметов в хотбар или выбрасыванием, если он заполнен. Слоты экипировки не затрагиваются.

Отмычка предусмотрена как следующий этап разработки и пока не реализована.
- Персональный денежный баланс игрока сохраняется в данных игрока и отображается в левом верхнем углу HUD.
- Передача денег: нажать ПКМ по другому игроку с расстояния до 8 блоков, ввести сумму и подтвердить перевод. Сервер проверяет баланс, дистанцию и сумму; перевод синхронизируется обоим игрокам.
- Начальный баланс равен 0; система начисления/заработка денег пока не добавлена.

## Требования

- Minecraft 1.20.1
- Minecraft Forge 47.x
- Java 17
- Gradle Wrapper (пока не добавлен)

## Сборка

После добавления Gradle Wrapper:

```bash
./gradlew build
```

Готовый JAR появится в `build/libs/`.
