# TZ — Minecraft Forge 1.20.1

Проект мода для Minecraft 1.20.1 на Minecraft Forge.

## Статус

Начальная подготовка репозитория. Архитектура и функциональность мода будут определены после уточнения требований к обработке карты.

## Требования разработки

- Minecraft 1.20.1
- Minecraft Forge 47.x
- Java 17
- Gradle Wrapper

## Сборка

После добавления Forge MDK и Gradle Wrapper:

```bash
./gradlew build
```

Готовый JAR появится в `build/libs/`.
